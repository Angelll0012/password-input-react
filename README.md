# Password Tracker

## Description
A simple React application that demonstrates React components and event handling.

## Components

- **App:** Parent component that connects PasswordInput and SubmitButton.
- **PasswordInput:** Displays a password field and tracks changes using the onChange event.
- **SubmitButton:** Displays a Submit Password button and tracks mouse movements using onMouseEnter and onMouseLeave.

## Technologies
- React
- JavaScript
- HTML
- CSS
- Vite
